# Vincere Knapsack — Quantum Optimization

**Qiskit Fall Fest 2026 | Quantum Optimization Track | PS-O3**

## About the Project

Vincere Knapsack explores the **Combinatorial 0/1 Knapsack Problem** using Qiskit and quantum optimization techniques.

The objective is to select a subset of items that maximizes total value while keeping the total weight within the knapsack capacity.

The project compares quantum optimization results against an exhaustive classical baseline and evaluates solution feasibility, objective quality, circuit resources, and processor configurations.

The project is evaluated according to the Qiskit Fall Fest 2026 Quantum Optimization judging rubric, including:
