# Vincere Knapsack — Quantum Optimization

**Qiskit Fall Fest 2026 | Phase 2 | PS-O3**

Vincere Knapsack explores resource-constrained item selection using Qiskit and the Quantum Approximate Optimization Algorithm (QAOA).

The project investigates how QUBO formulations, quantum circuit execution, processor connectivity and noise affect the quality and feasibility of solutions to the 0/1 Knapsack Problem.

## Problem Statement

Select a subset of items to maximize total value while keeping total weight within the knapsack capacity.

The project compares quantum optimization results against an exhaustive classical baseline.
