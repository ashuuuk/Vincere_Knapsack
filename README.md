# Vincere Knapsack — Quantum Optimization

**Qiskit Fall Fest 2026 | Phase 2 | Problem Statement PS-O3**

## 1. Overview

Vincere Knapsack explores resource-constrained item selection using quantum optimization. The project models a 0/1 Knapsack Problem, where each item has a value and a weight, and the total selected weight must not exceed the available capacity.

The objective is to maximize the total value of selected items while satisfying the capacity constraint.

## 2. Problem Statement

Given a set of items, each with a value \(v_i\) and weight \(w_i\), select a subset that maximizes the total value without exceeding the knapsack capacity.

Let \(x_i \in \{0,1\}\) indicate whether item \(i\) is selected.

**Objective:**

Maximize the total value:

\[
\max \sum_i v_i x_i
\]

**Constraint:**

\[
\sum_i w_i x_i \leq W
\]

where \(W\) is the maximum capacity.

## 3. Approach

The project investigates quantum optimization using:

- **QUBO formulation:** Converts the constrained optimization problem into a quadratic unconstrained binary optimization objective.
- **QAOA:** Uses the Quantum Approximate Optimization Algorithm to search for high-quality candidate solutions.
- **Classical benchmarking:** Exhaustively evaluates feasible item subsets to establish the exact optimal solution.
- **Processor comparison:** Evaluates solution quality and circuit performance across the required processor configurations.
- **Noise analysis:** Compares ideal and noisy simulation results to study the effects of quantum noise.

The final implementation follows the official Phase 2 problem instance and configuration requirements.
